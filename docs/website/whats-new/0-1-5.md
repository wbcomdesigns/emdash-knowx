# What's new in 0.1.5

**Included in Free.** KnowX has no paid version.

- **Guests and visitor addresses (security).** Guests vote on **Was this helpful** and have their searches counted only when the host gives EmDash the visitor's address: on Cloudflare, or with `trustedProxyHeaders` in `astro.config.mjs`. On other hosts a guest who votes is asked to sign in, searches are not counted, and signed-in members vote as usual. **KnowX, Insights** says so in one line. See [Guests and visitor addresses](../getting-started/install.md#guests-and-visitor-addresses).
- **A safer search log (security).** It keeps the latest 5000 terms. A search that found nothing stays on **Searches with no results** for 30 days, and nobody can clear it by sending a made-up result. Phone numbers typed with dashes or brackets are never stored.
- **One command for the kit.** `scripts/add-to-site.sh` copies the site kit, keeps your wording file if you changed it, creates the Help articles and FAQs content types, and prints what is left to do.
- **Set up visitor pages.** **Insights** opens with the two kit lines for the version you installed, and says where to add your first help article and FAQ (**Content, Help articles** and **Content, FAQs**).
- **Fits the theme frame.** The help pages line up with your header and footer, and dark mode buttons are easier to read.

Copy the site kit again after you update: run step 2 of [Install](../getting-started/install.md) with the new tag.
