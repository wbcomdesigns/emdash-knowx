# What's new in 0.1.2

**Included in Free.** KnowX has no paid version.

- After a vote, the chosen button stays highlighted, and a sent comment is confirmed and its box closes.
- "Still need help?" under an article has even spacing.
- Screen readers hear "2 of 3 readers found this helpful" instead of a bare count.
- Full user guides for site owners: install, help pages, search, feedback, Insights, settings, FAQ and troubleshooting.
- The install guide copies the two shared kit files only when your site's copy is older, so another Wbcom plugin's newer copy is never replaced.
