# What's new in 0.1.1

**Included in Free.** KnowX has no paid version.

Copy the site kit again after you update.

## For visitors

- The help home shows topics and a list of articles.
- Topic cards, search results, FAQ rows and article extras share one tidy card style. The first FAQ answer is open.
- Article pages: table of contents, previous and next and related articles as cards; copy link is an icon.
- Long searches wrap, and help pages sit in your theme's column.
- Dark mode stays readable even when the rest of the page stays light.

## For site owners

- The kit finds the plugin on a registry install, so votes and the search log save.
- Settings uses tabs. Insights opens with counts and a search chart.
