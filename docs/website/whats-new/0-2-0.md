# What's new in 0.2.0

**Included in Free.** KnowX has no paid version.

No new permission. The site kit has not changed, so you do not have to copy it again; the setup card on **Insights** comes back once after the update, and copying the 0.2.0 kit is safe.

- **Fits Cloudflare's request limit.** On Cloudflare each plugin call may make 10 requests to the site. Every help page, vote, search, admin screen and button now stays within it on a busy help centre, so a guest vote no longer shows "Something went wrong" after it was saved, and Insights and Settings no longer fail.
- **Running totals.** Each article keeps its Yes and No counts, updated in the same step as the vote, and the site keeps its search counts per day and its helpful rate. Both screens open in a few reads on any size of site. The stored votes stay the record.
- **A new Searches screen.** **Top searches** and **Searches with no results** moved from **Insights** to **KnowX, Searches**. Insights keeps the counts, the chart, the least helpful articles and the recent comments.
- **Updating from 0.1.x.** Votes, comments and search counts from before the update are brought over the first few times you open **Insights**, about 100 votes each time, with **Continue** until it says **Insights is ready**. See [Insights](../features/insights.md#after-updating-from-01x).
- **Articles count.** Past 100 published articles, **Articles** on Insights shows **100+**.
- **Setup card wording.** The card no longer says the command creates the content types on every host. It does on a site with a local SQLite database; on any other site (Cloudflare D1) create them in the admin: [Install](../getting-started/install.md#create-the-content-types-in-the-admin).
- **Visitor pages are set up stays.** The answer is saved with the plugin version, so the card stays one line after a reload and comes back only after an update.
