# What's new in 0.2.2

**Included in Free.** KnowX has no paid version.

No new permission. Nothing in the site kit changed, so copying it again with the 0.2.2 tag is optional; the 0.2.1 kit keeps working.

- **Install check.** The plugin registry now checks that your site runs EmDash 1.2.0 or later before it installs KnowX, instead of the install failing later on an older site.
- **FAQ structured data.** A page for a single FAQ entry no longer tells search engines it is an FAQ page without listing its question and answer, which schema validators reported as an error. It keeps its breadcrumbs. The FAQ page at **/docs/faq/** still lists every question and answer for search engines, as before.
