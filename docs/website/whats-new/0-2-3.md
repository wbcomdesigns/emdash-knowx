# What's new in 0.2.3

**Included in Free.** KnowX has no paid version.

No new permission. The site kit changed: copy it again with the 0.2.3 tag after you update (the command is on the install page).

- **Admins-only page.** EmDash lists a plugin's admin pages to every signed-in role. A member below admin who opens Insights, Searches, Settings or the dashboard card now sees "Only site admins can use KnowX" instead of a raw permission error. Nothing is read or changed for them.
- **Every article on the help home.** The Articles list at **/docs/** shows the newest ten, with **More articles** to page through the rest, so an article in no topic can still be found by browsing.
- **More search results.** The search page shows 20 results at a time with **More results**. Only the first page of a search is counted in Searches.
- **On this page first.** On a phone the article's **On this page** list sits above the article instead of at the very end. It also comes before the article in keyboard order on every screen; on wide screens it stays beside the article.
- **Your vote stays marked.** After you press Yes or No, the button stays marked as chosen when you reload the article in the same browser.
- **Named copy link buttons.** Each heading's copy link button now says which heading it copies, for screen reader and keyboard users.
- **Cloudflare note.** The install text says to deploy again after every registry install or update on Cloudflare, until EmDash ships its fix.
