# What's new in 0.1.3

**Included in Free.** KnowX has no paid version.

- One command creates the help collections with search turned on: `npx emdash seed path/to/emdash-knowx/site-kit/seed/knowx-seed.json --no-content`. It never changes your menus. See [Install](../getting-started/install.md).
- New guides: [Use cases](../getting-started/use-cases.md) and [Use it on blog posts and pages](../getting-started/posts-and-pages.md).
- Related articles under an article no longer repeat the ones already linked as Previous and Next.
- When pages are included in help search, a page result opens the page at its real address on the blog template.
- The help center follows your site's light or dark choice, so it stays readable when a visitor picks light mode on a device set to dark.

Copy the site kit again after you update.
