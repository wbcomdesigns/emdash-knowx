# What's new in 0.2.1

**Included in Free.** KnowX has no paid version.

No new permission. Copy the site kit again with the 0.2.1 tag for the vote fix below. The 0.2.0 kit keeps working with this version until you do.

- **Insights after updating from 0.1.x.** Until the votes and search counts from 0.1.x are all brought over, every time you open **Insights** it shows **Bringing over data from KnowX 0.1** and **Continue**, then **Insights is ready**. In 0.2.0 the first loads could show **Helpful rate: None yet** and **No weak articles yet** on a small site, so the data looked lost. It never was. See [Insights](../features/insights.md#after-updating-from-01x).
- **New sites are not held up.** A site with nothing from 0.1.x shows the full **Insights** page the first time it opens.
- **Early clicks on Was this helpful.** On a cold load (the first visit after a deploy on Cloudflare) the page script can start a few seconds after the buttons show. A **Yes** or **No** clicked in that time now shows as being sent and is sent as soon as the script runs, instead of being lost.
