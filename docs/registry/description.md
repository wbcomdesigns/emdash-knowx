KnowX turns an EmDash site into a help center. Visitors search for an answer, browse topics, and say whether an article helped. You see which searches find nothing and which articles get more No votes than Yes.

## What you get

- **Help home.** A search box and topic cards. When you have more than one top-level category, each card shows a name, a short description and an icon you pick.
- **Articles.** Table of contents, copy-link on headings, copy on code, previous and next, last updated date, optional version badge.
- **Search.** EmDash's own search, limited to the content types you tick. Instant results as you type, plus a results page. Each result says what kind of content it is.
- **FAQ.** Its own page, with FAQ data for search engines.
- **Was this helpful.** Yes or No on each article. After a No you can ask for a short comment.
- **Still need help.** A contact button after an empty search and after a No vote. You set one link. Hidden when that setting is empty.
- **Insights.** Weak articles by name, comments as plain text, top searches, searches that found nothing.
- **Dashboard card.** Empty searches this week, and the least helpful article.

## How it fits together

KnowX is the engine: routes, storage and the admin screens. An EmDash plugin cannot add pages to your site, so the public pages ship as a site kit you copy in once. See Installation.

Every visitor-facing feature works for guests. Signing in changes nothing.
